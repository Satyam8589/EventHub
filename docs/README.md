## 📋 Feature Overview

The **Event Report Generation** feature allows super admins to:
1. Generate comprehensive AI-powered reports for any event
2. Automatically send reports via email to event organizers
3. Include detailed analytics, user information, and AI-driven insights
4. Access reports with a single click from the admin dashboard

---

## 🔑 Key Technologies

- **AI**: Google Gemini AI (gemini-1.5-flash)
- **Email**: Nodemailer with Gmail SMTP
- **Database**: Supabase (PostgreSQL)
- **Framework**: Next.js 16
- **Language**: JavaScript/React
